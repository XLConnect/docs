# XLConnect Documentation

XLConnect extends Excel with data management, automation, version control and governance — so the workbooks you already build can behave like cloud applications. Read data from APIs, write it to a data lake, and refresh hundreds of workbooks automatically.

New here? Start with [What is XLConnect?](what-is-xlconnect.md), then [install the add-in](installing-the-add-in.md).
