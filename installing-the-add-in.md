# Installing the add-in

<!-- TODO: re-capture screenshots for the current installer and account page -->

The Excel add-in can be installed from [your account page](https://account.xlconnect.net). On the start page there is a download section.

{% hint style="info" %}
XLConnect works only on Excel for Windows. To use it on a Mac, run the Windows version of Excel in a virtual machine such as Parallels.
{% endhint %}

1. Click the `Install` button to download the installer file `XlConnect.Add-InSetup(x.x.x).msi`.
2. Double-click the file to begin the installation.
3. Hit `Next` until the installation finishes to install with default settings (recommended).

When the installation is finished it will launch Excel with a welcome workbook. Follow the instructions in there to log in and open your start page.

## Launching XLConnect

XLConnect integrates with Excel — **launch Excel** to start using it. There will be a new `XLConnect` ribbon.

## Removing XLConnect

To remove XLConnect from your computer:

1. Go to the `Add or remove programs` settings page.
2. Search for `XLConnect`.
3. Press `Uninstall`.
