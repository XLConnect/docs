# Data Lake (XLC)

The XLC data lake stores messages in the XLConnect database. It is used by existing workbooks and the [message methods](../reference/the-xlc-object.md#messages) on the xlc object.

{% hint style="info" %}
For new work we recommend the [SharePoint Data Lake](data-lake-sharepoint.md) instead — the syntax is easier and your data stays on your own Office 365 subscription.
{% endhint %}
